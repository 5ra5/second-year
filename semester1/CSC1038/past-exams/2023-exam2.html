1. Numbers in the middle

Centre elements are defined as the number(s) stays in the exact middle of the list after the list has been sorted.

Write a program ex2-two-median.c which accepts input as an array of integer. Given that the number of elements of the array is always even, the program finds the two centre elements and displays both of them in the ascending order line by line.

You can assume that the maximum number of elements in the array is 100.

Input

./ex2-two-median 8 3 10 2 -4 -6 0 9

Output

2
3

Explain: The input array can be sorted as follow

-6 -4 0 2 3 8 9 10

So the two center elements are 2 and 3 in this case.

Input

./ex2-two-median 8 4 10 2 1 -4 -6 0 9 10

Output

2
4
Note
 You are encouraged to use function and pointers as much as you can to design the solution, and show your ability to use pass by reference mechanism in this exam task.

2. Let’s go shopping

You are making a shopping management software to be used in self-checkout machines in groceries. The program accepts the information of a list of shopping items in a cart. Each item in the cart contains the following information:

  • Item (you can assume it is a string of maximum 20 characters)

  • Amount (an unsigned integer number)

  • Price (a floating number - price per item)

  • Promotion: promotional status of the item as a binary value (1 = the item is on sale, 0 = no promotion)

2.1. What do I buy?

Write a program ex2-show-cart.c which accept the input above. The program can then print all entered items infomation, each item details are displayed in one line. Note that, for the promotion infomation, if promtion value = 1, the sale status is On Sale, otherwise No Sale.

Input

./ex2-show-cart "Cucumber" 5 1.0 0 "Guinness" 4 2.5 0 "Tayto" 10 2 1

Output

Cucumber,5,1.00,No Sale
Guinness,4,2.50,No Sale
Tayto,10,2.00,On Sale

Note that:

  • You need to print a floating number with two digits after the decimal point.

  • You can assume the maximum number of input items is 100.

  • You can also assume that the number of arguments are always completed.

  • You are encouraged to write the input and printing procedures as separate functions instead of writing everything in the main function.

Note
 Use function and pointers as much as you can to design the solution.

2.2. How much do I have to pay? (Don’t forget my discount!!!)

Write a program ex2-discount.c which accepts the information of a list of shopping items as described above. The program calculates the final amount to pay for all items in the cart and and prints the result with 2 digits after the decimal point.

Note that you have to consider the promotion status of each item in the cart. In particular, the amount of money to pay for each item is equal to the price per unit x amount normally. However, for every three promotional items, the customer only needs to pay for two.

You can assume the maximum number of input items is 100 and the number of arguments are always completed.

Input

./ex2-cart "Cucumber" 5 1.0 0 "Guinness" 4 2.5 0 "Tayto" 10 2 1

Output

29

Explain:

  • Cucumber and Guiness have no promotion, so the price for them can be easily calculated as 1.0 x 5 + 2.5 x 4 = 15;

  • Tayto is on sale (promotion = 1), so customer only needs to pay for each three items with the price for two. So with 10 Tayto items, the customer needs to pay for the first 9 items with the price for 6 items, plus the last item with full price. So the amount of money for Tayto is: 2 x 6 + 2 = 14;

  • So the total amount of money to be paid for this shopping cart is 15 + 14 = 29;

Note
 Use function and pointers as much as you can to design the solution.
