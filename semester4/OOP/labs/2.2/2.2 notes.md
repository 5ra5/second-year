## arrays and arrayLists in java

```java
public class ArrayExample {
	public static void main(String[] args){
		// Declaration and initialization
		int[] numbers = {1, 2, 3, 4, 5};
		
		// Accessing elements
		System.out.println("First number: " + numbers[0]); // Output: 1
		
		// Modifying an element
		numbers[2] = 10;
		
		// Iterating through the array
		System.out.println("Array elements: ");
		for (int number : numbers){
			System.out.println(number);
		}
	}
}
```

output:
```
First number: 1
Array elements: 1 2 10 4 5
```

## arrayLists in java

```java
import java.util.ArrayList;

public class ArrayListExample {
	public static void main(String[] args) {
		// Create an ArrayList of Strings
		ArrayList<String> names = new ArrayList<>();
		
		// Add elements
		names.add("Alice");
		names.add("Bob");
		names.add("Charlie");
		
		// Access elements
		System.out.println("First name: " + names.get(0)); // Output: Alice
		
		// Remove an element
		names.remove("Bob");
		
		// Iterating through the ArrayList
		System.out.println("Remaning names:");
		for (String name : names){
			System.out.println(name);
		}
	}
}
```
## understanding classes and objects

1.  **Class**: defines the structure and behaviour (methods of objects), and contains attributes (fields) and methods to represent and manipulate data
2.  **Object**: an instance of a class, it has state (values of its attributes) and behaviour (methods it can perform)

### access modifiers

`public`
-  allows unrestricted access to a class, method or variable from any other class
-  used for components that need to be accessed by other parts of the program

`private`
-  restricts access to a class, method or variable to within the same class, it cannot be accessed from outside the class
-  used to enforce encapsulation and protect sensitive data

```java
public class Person {
	private String name;
	private int age;
	
	// Public constructor
	public Person(String name, int age) {
		this.name = name;
		this.age = age;
	}
	
	// Public getters and setters
	public String getName() {
		return name;
	}
	
	public void setName(String name) {
		this.name = name;
	}
	
	public int getAge(){
		return age;
	}
	
	public void setAge(int age){
		if (age > 0) { // Validation
			this.age = age;
		}
	}
}
```
